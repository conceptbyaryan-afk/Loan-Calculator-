# Loan A/C Calculator (installable web app)

Files: index.html, core.js (calculation), sw.js (offline + updates), manifest, icons/.

## Put it online (one time, free)
1. github.com > New repository (name it e.g. `loan-calc`).
2. Upload ALL files in this folder (keep the `icons` and `.github` folders).
3. Repo > Settings > Pages > Source: "GitHub Actions".
4. Wait ~1 min. Your link: https://<your-username>.github.io/loan-calc/
5. Open the link in Chrome on the phone > menu > "Install app" (or the Install button in the page).

## Update later
Replace the changed files in the repo (e.g. index.html). The phone gets the new version
next time the app is opened with internet. No reinstall.
